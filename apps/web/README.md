# React frontend

See [the repository README](../../README.md) for setup and commands. This create-vite React/TypeScript scaffold implements login, product reservation, customer list/detail/cancellation, and read-only operations inspection. Shared Tailwind/daisyUI components support both roles; React Query manages API state and React Hook Form/Zod centralize forms. The session is kept in React state and in same-tab `sessionStorage` (`inventory.session`) so checkout can return signed in; sign-out removes it. The webhook secret is API-only. A pending customer order can start the optional payment gateway with **Pay**.
